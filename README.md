# 🔢 Base Converter

A lightweight and interactive **web app** that converts numbers between different bases such as **binary**, **decimal**, and **hexadecimal**.  
Built using **HTML**, **CSS**, and **JavaScript**, focusing on clean UI, responsive layout, and simple logic.

---

## 🧩 Features
- Convert numbers between multiple bases (2–16)  
- Instant real-time conversion  
- Input validation for incorrect or unsupported values  
- Minimal and user-friendly interface  

---

## 💻 Technologies Used
- **HTML5** – Structure and input fields  
- **CSS3** – Styling and responsive design  
- **JavaScript** – Logic, base conversion, and DOM manipulation
